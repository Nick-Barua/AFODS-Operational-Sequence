# AFODS Operational Sequence Documentation

This repository provides supplementary documentation and the core diagram for the operational sequence of the Advanced Falling Object Detection System (AFODS), supporting the academic manuscript ** https://doi.org/10.3390/vehicles7040149 **.

## 🖼️ Figure Overview

The Graphical Abstract (GA) and the five-stage processing diagram illustrate the advanced data processing pipeline designed for proactive threat detection, detailing the sequential flow from initial sensor data acquisition (LWIR, NIR, Ultrasonic) to the final decision and action stage.
